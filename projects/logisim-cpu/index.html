What I built

The ECE 212 datapath project explores how digital logic becomes a programmable machine. An 8-bit datapath connects the arithmetic logic unit, eight registers, instruction decoder, control store, and program counter. A custom instruction set exposes arithmetic, logic, branching, clearing, and termination.

My contribution

Designed and simulated the datapath and documented its instruction syntax and microarchitecture. Chained 4-bit ALU sections support 8-bit operations; registers retain results and the program counter selects the next instruction. A division program demonstrates a conditional loop.

  • Eight 8-bit registers and a separately controlled program counter.
  • NOT, OR, AND, ADD, and SUBTRACT operations.
  • Conditional branches and program termination.
  • A division example executed through repeated arithmetic and branching.

Components

Architecture

ALU, eight registers, instruction decoder, control store, and program counter.

Programs & iterations

Custom instructions, conditional branching, division example, and saved Logisim revisions.

Design choices

  • Make the connection between instruction fields and datapath controls explicit.
  • Use conditional program-counter updates to implement loops.
  • Build and inspect the machine at the logic-component level.

Scope & results

The original design is a Logisim simulation. This browser teaching model demonstrates the datapath concepts with a readable example instruction notation; it does not emulate the exact original machine-code bit format.
