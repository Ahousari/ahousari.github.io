What I built

The CSV-to-document project automates repetitive document preparation. It reads CSV/Excel data, substitutes named placeholders in a Word template, and packages generated documents with configurable filenames. Both a command-line program and a Flask web version are part of the project.

My contribution

Developed the data/template upload workflow, placeholder replacement, filename patterns, output handling, and browser interface around the document-generation process.

  • CSV and Excel inputs with Word templates.
  • Named placeholders tied to data-column headers.
  • Configurable document filenames.
  • Batch generation and ZIP output; PDF conversion through a local document application.

Components

Command-line tool

Original script-based document-generation workflow.

Web application

Flask upload interface, batch processing, and ZIP download.

Design choices

  • Let a familiar Word template define the document layout.
  • Use readable placeholder names that match source columns.
  • Separate document generation from system-dependent PDF conversion.

Scope & results

The browser sample demonstrates placeholder substitution and downloads a text result. Full Word/PDF generation belongs to the local application and its document-conversion dependencies.
