What I built

This MATLAB project compares PI and model predictive cruise-control behavior using a shared road profile and vehicle-motion simulation. It examines how each controller responds to slope changes through speed, acceleration, and summary statistics.

My contribution

Developed the simulation scripts and comparison workflow, including a variable road profile, time-stepped vehicle motion, controller logic, plots, and statistical summaries.

  • Shared reference speed and road profile for comparison.
  • Vehicle response to the gravitational component of road slope.
  • Speed and acceleration plots.
  • Summary statistics for comparing controller behavior.

Components

MATLAB simulations

PI, predictive-control, and shared comparison scripts.

Analysis

Speed, acceleration, road profile, and summary-statistic outputs.

Design choices

  • Use a common simulation context when comparing controllers.
  • Inspect both tracking error and acceleration.
  • Keep the vehicle model’s assumptions visible.

Scope & results

The public sample compares PI feedback with a simplified road-preview feed-forward controller. It illustrates the comparison question and is not the original MATLAB MPC implementation or a validated vehicle model.
