What I built

Pocket Bridge connects an iPhone and a Windows computer for sending files, capturing photos, scanning multi-page PDFs, and downloading computer files back to the phone. Transfers arrive in Downloads without replacing existing files. A cached interface can retain pending documents while the computer is unavailable.

My contribution

Developed the cross-device web application, local pending-document workflow, retry/receipt handling, scanner interface, sign-in, and bounded file-transfer service. The application uses a private connection to the computer and supports remembered devices without exposing a personal installation publicly.

  • Two-way file access between phone and computer.
  • Camera capture and perspective-corrected multi-page PDF scanning.
  • Offline pending documents with explicit retry and delivery confirmation.
  • Streamed transfers, duplicate-name handling, and a restricted Downloads boundary.

Design choices

  • Distinguish bytes uploaded from a file successfully saved on the computer.
  • Retain pending copies until delivery is confirmed.
  • Keep account state and personal files outside the distributable application.

Scope & results
