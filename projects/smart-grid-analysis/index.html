What I built

This ECE 4160 project uses recorded IEEE 68-bus scenarios to explore disturbances and predict their event type and affected area. Interactive viewers make time-series behavior inspectable alongside an MLP training and results workflow.

My contribution

Developed the Grid Explorer and standalone viewing tools, baseline-relative feature pipeline, grouped cross-validation workflow, classifier comparison, and saved results presentation. The explorer uses supplied scenario labels to explain recordings; those annotations are not model predictions.

  • 180 scenarios across five loading conditions.
  • Original and v2 Grid Explorer plus a standalone viewer.
  • MLP event/area prediction using 1,920 derived features.
  • Grouped validation keeps loading variants of an event template in one fold.

Components

Grid exploration

Original/v2 explorers and a standalone recorded-signal viewer.

Event classification

MLP training, grouped validation, scenario-level test, and results viewer.

Design choices

  • Display channels as recorded without inventing missing measurements.
  • Fit feature standardization inside cross-validation folds.
  • Explain why scenario-level testing differs from unseen-template validation.

Scope & results

The saved model has 94.4% joint accuracy on 36 scenario-level test cases; mean grouped-CV joint accuracy is 53.8%. The public animation below is a conceptual generated disturbance, not a replay of those recordings or a live grid.
