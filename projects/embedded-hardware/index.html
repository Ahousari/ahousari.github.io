What I built

These projects connect software decisions to physical interfaces. The microcontrollers alarm-clock team project uses a rotary encoder, a four-digit display, timer behavior, and an LED alarm indicator. Earlier GE Next Engineers work reads an analog signal and commands a stepper motor.

My contribution

Contributed to the alarm-clock design and firmware with Omar Housari, working through display communication, encoder interrupts, and control states. The earlier Arduino program ties a voltage threshold to opposite motor movements.

  • Rotary-encoder input and interrupt handling.
  • SPI communication with a shift-register-based display.
  • Clock/alarm setting states and timer behavior.
  • Analog threshold sensing and stepper-motor control.

Design choices

  • Work through peripheral behavior with direct hardware testing.
  • Use control states to separate display and setting modes.
  • Document the implemented prototype rather than the original wish list.

Scope & results

The alarm prototype used an LED to represent the intended relay output and did not complete the planned real-time-clock implementation. The browser sample illustrates the interface states without controlling hardware.
